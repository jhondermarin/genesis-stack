# Project Principles

## 1. Simplicity First

Choose the simplest solution that solves the problem.

---

## 2. Readability Matters

Code is read more often than it is written.

---

## 3. Consistency Over Cleverness

Follow established conventions across the entire ecosystem.

---

## 4. Reusability

Avoid duplication.

Shared logic belongs in reusable modules.

---

## 5. Documentation First

Important decisions must be documented before implementation.

---

## 6. Type Safety

TypeScript should prevent errors before runtime.

---

## 7. Docker First

Every project must run consistently using Docker.

---

## 8. Modular Design

Applications should be built from independent modules.

---

## 9. Continuous Improvement

The stack evolves through small, well-documented iterations.

---

## 10. Build for the Future

Every decision should make future projects easier to maintain.

## 11. Build Progressively

Project structure should evolve with the application.

Avoid creating folders, files or abstractions before they are needed.
