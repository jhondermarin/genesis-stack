# ADR-005

## Title

Use Tailwind CSS.

---

## Status

Accepted

---

## Context

Genesis Stack requires a modern styling solution that promotes consistency and rapid development.

---

## Decision

Tailwind CSS will be the default styling framework.

---

## Consequences

### Positive

- Rapid UI development.
- Consistent design.
- Excellent ecosystem.
- Perfect integration with shadcn/ui.

### Negative

- Utility-heavy HTML.
- Initial learning curve.

---

## Alternatives Considered

- Bootstrap
- CSS Modules
- Styled Components
