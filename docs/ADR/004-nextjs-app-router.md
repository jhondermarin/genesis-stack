# ADR-004

## Title

Use Next.js App Router.

---

## Status

Accepted

---

## Context

Next.js provides two routing systems.

Genesis Stack should use the modern architecture.

---

## Decision

App Router will be the default routing solution.

---

## Consequences

### Positive

- Server Components.
- Better layouts.
- Better loading states.
- Better future compatibility.

### Negative

- Learning curve.
- Some older tutorials use Pages Router.

---

## Alternatives Considered

- Pages Router
